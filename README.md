# 🚗 Vehicle Rental Management System (Qt C++)

A desktop application built using **Qt 6 (C++)** for managing vehicle rentals.  
This system allows users to add vehicles, rent them out, return them, and track rental history.

---

## 📌 Features

- Add new vehicles (Car / Motorcycle)
- Rent vehicles to customers
- Return rented vehicles
- Remove vehicles
- View rental history
- Dynamic UI updates when selecting vehicles

---

## 🛠️ Technologies Used

- C++
- Qt 6 (Qt Widgets)
- CMake
- MinGW (64-bit)

---

## 🖥️ Application UI

- Table displays all vehicles
- Selection auto-fills vehicle details
- Rental history toggle view and you can hide it
- Status color indicators:
  - 🟥 Red = Rented
  - 🟩 Green = Available
- Option to refresh the page
- Costomer name
- Number of days to rent a vehicle
- Calculates the total revenue
